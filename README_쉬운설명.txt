똑똑 v1.1 사용 설명서

1. 파일 구성

index.html
- 처음 접속했을 때 학생용/교무실용 화면을 선택하는 입구 화면입니다.

student.html
- 학생용 프로그램입니다.
- 학생이 교무실, 선생님, 요청 내용, 긴급도를 선택하고 “똑똑!” 버튼을 누릅니다.
- “조용히 똑똑하기”를 선택하면 교무실 음성 안내 없이 시각 알림 중심으로 호출됩니다.
- 선생님이 학생을 부르면 “선생님이 보낸 호출” 영역에 크게 표시됩니다.

office.html
- 교무실용 프로그램입니다.
- 선택한 교무실의 호출만 확인할 수 있습니다.
- 새 호출이 들어오면 “똑똑!”으로 시작하는 안내가 표시됩니다.
- 음성 알림을 꺼도 새 호출 카드는 깜빡이며 표시됩니다.
- 선생님은 “지금 오세요 / 점심시간에 / 수업 후에 / 잠시 기다려요 / 처리 완료”로 응답할 수 있습니다.
- 호출 기록 리셋 버튼으로 선택한 교무실의 호출 기록을 삭제할 수 있습니다.

style.css
- 전체 디자인을 담당합니다.
- v1.1에서는 교실, 나무문, 따뜻한 학교 분위기를 살린 디자인으로 수정했습니다.

common.js
- 교무실 목록, 선생님 명단, 공통 함수가 들어 있습니다.
- 학생용과 교무실용이 함께 사용하는 기능입니다.

firebase-config.js
- Firebase 연결 설정 파일입니다.
- 현재 프로젝트 설정값이 들어 있습니다.

3. 주소 예시

GitHub Pages 주소가

https://아이디.github.io/저장소이름/

이라면 학생용 주소는

https://아이디.github.io/저장소이름/student.html

교무실용 주소는

https://아이디.github.io/저장소이름/office.html

입니다.


4. 주요 기능

- 교무실 선택
- 교무실별 선생님 선택
- 학생 → 선생님 호출
- 선생님 → 학생 호출
- 조용한 호출
- 긴급도 구분
  일반: 기본
  빠른 확인 필요: 주황색
  긴급: 빨간색
- 중복 호출 방지
- 교무실 혼잡도 확인
- 음성 알림 ON/OFF
- 음성 OFF 상태에서도 새 호출 카드 깜빡임
- 호출 기록 CSV 다운로드
- 호출 기록 리셋
