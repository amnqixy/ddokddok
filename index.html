교실과 3학년 교무실을 연결하는 실시간 호출 시스템

화면 선택

학생은 학생용 화면을, 교무실에서는 교무실용 화면을 열면 됩니다.

학생용 프로그램 열기 교무실용 프로그램 열기

사용 순서

1. Firebase 설정을 완료합니다.
2. GitHub Pages에 이 파일들을 올립니다.
3. 학생은 student.html, 교무실은 office.html을 엽니다.
4. 학생이 똑똑! 버튼을 누르면 교무실 화면에 실시간으로 표시됩니다.
