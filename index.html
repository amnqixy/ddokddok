똑똑 v1.1

교실에서 교무실 문을 조심스럽게 두드리는 실시간 호출 시스템

어서 오세요, 똑똑입니다.

학생은 학생용 화면에서 선생님께 호출을 보내고,
교무실에서는 교무실용 화면으로 호출을 실시간 확인합니다.

학생용 프로그램 열기 교무실용 프로그램 열기

사용 순서

1. 학생은 student.html을 엽니다.
2. 교무실에서는 office.html을 엽니다.
3. 학생이 똑똑!을 누르면 교무실 화면에 바로 표시됩니다.
4. 선생님은 “지금 오세요 / 점심시간에 / 수업 후에 / 잠시 기다려요 / 처리 완료”로 응답할 수 있습니다.
